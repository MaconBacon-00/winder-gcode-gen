Times assume each move runs at its commanded speed (no acceleration), so the real wind is a little slower. Keys: Space play/pause, ←/→ move, Shift+arrows layer. Which way the mandrel turns depends on the machine (+Y direction).

Config reference

Required: mandrel_diameter, band_width, x_start, x_end (mm) and layers.

  • {"type": "hoop", "passes": 2}
  • {"type": "helical", "angle": 45, "skip": 1, "pattern": 5} (pattern optional)
  • Per helical layer or global: min_dwell, lead_in_mm, lead_out_deg. Any layer: thickness.
  • Global: carriage_speed, mandrel_speed, head_speed, travel_speed, accel, lead_segments, hoop_dwell, layer_thickness, head_enabled, head_gain, pause_to_align, pause_at_end, name.
